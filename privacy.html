「오늘의 테마」 업로더는 운영자 본인의 유튜브 채널에 그날의 테마 정리 영상을 올리는 자동화 도구입니다. 다른 사람이 로그인하거나 사용하는 서비스가 아닙니다.

Google 사용자 데이터 이용

  • 요청 권한: youtube.upload(영상 업로드), youtube.readonly(같은 날 영상이 이미 올라갔는지 운영자 채널의 업로드 목록 확인).
  • 운영자 본인 채널 외의 데이터에는 접근하지 않습니다.
  • 받은 데이터를 저장·판매·공유하지 않으며, 광고나 분석에 쓰지 않습니다.
  • 인증 토큰은 GitHub Actions 암호화 비밀값(Secrets)에만 보관합니다.

권한 철회

Google 계정 → 타사 액세스에서 언제든지 이 앱의 권한을 해제할 수 있습니다.
